# 图片评测清单与调优决策树 — Review Checklist

> 用于Step 4：用户回传生成结果后，系统化评测画面质量并定向调优。

---

## 1. 六维评测体系

每次评测从以下6个维度打分（1-5分），确定问题的根本原因。

### 维度一：🎯 整体印象 — 由🎭AD负责

| 分数 | 标准 | 典型用户反馈 |
|------|------|-------------|
| 5 | 第一眼就被击中，完全符合预期 | "就是这个感觉！" |
| 4 | 基本满意，小细节可优化 | "不错，但可以更XX一点" |
| 3 | 及格但缺乏惊喜 | "还行，但感觉不太对" |
| 2 | 偏离方向，需要大改 | "不是我要的感觉" |
| 1 | 完全错误 | "这跟我想的完全不一样" |

### 维度二：🎨 风格匹配度 — 由🎨风格师负责

| 问题 | 检查点 |
|------|--------|
| 画面的主导风格是什么？ | 是否能清晰辨识？ |
| 风格是否符合用户意图？ | 是否有偏差？ |
| 风格是否一致（没有混搭冲突）？ | 有没有"半水墨半赛博"的撕裂感？ |
| 是否匹配设定的调性坐标？ | 重新对照创意简报 |

**常见问题 & 调优方向：**
- 风格不够鲜明 → 增加风格关键词权重，或加风格参考
- 风格混搭冲突 → 只保留一种主导风格，去掉冲突词
- 风格偏离需求 → 搜索知识库补充更精准的风格案例

### 维度三：📷 构图合理性 — 由📷摄影师负责

| 问题 | 检查点 |
|------|--------|
| 视线第一落点在哪里？ | 是否是设计好的主体位置？ |
| 主体是否突出？ | 背景是否喧宾夺主？ |
| 构图的引导线是否有效？ | 视线是否被引导到关键位置？ |
| 景深控制是否得当？ | 虚化是否服务于叙事？ |

**常见问题 & 调优方向：**
- 主体太小 → 拉近镜头（85mm→50mm 或 中景→特写）
- 画面杂乱 → 减少背景元素，加大景深压缩
- 构图不平衡 → 调整主体位置，三分法/对称/引导线
- 缺乏纵深感 → 加入前景锚点，应用三层法则

### 维度四：💡 光影说服力 — 由💡光影师负责

| 问题 | 检查点 |
|------|--------|
| 主光源方向是否明确？ | 阴影方向是否一致？ |
| 光影是否符合氛围设定？ | 治愈场景不能有恐怖片的光 |
| 是否有塑料感（AI常见问题）？ | 光影对比是否太假？ |
| 色彩氛围是否合适？ | 整体色调是否匹配情绪？ |

**常见问题 & 调优方向：**
- 塑料感/假光 → 调整光源方向，增加体积光或漫射描述
- 光线太平 → 增加对比度，指定阴影方向
- 色彩不对 → 调整色温关键词，指定主色调
- 氛围不足 → 加入空气透视（雾/霾/丁达尔效应）

### 维度五：🧱 材质真实感 — 由🧱材质师负责

| 问题 | 检查点 |
|------|--------|
| 主要材质是什么？ | 是否有清晰的质感描述？ |
| 材质与天气/环境匹配吗？ | 雨天应该有湿表面，晴天不该有雾气 |
| 是否有"AI光滑感"？ | 物体表面是否需要增加纹理？ |
| 细节是否足够？ | 近景是否需要更多微纹理？ |

**常见问题 & 调优方向：**
- 塑料感 → 增加表面纹理/凹凸/细微瑕疵描述
- 材质不对 → 更换材质关键词，参考材质-天气匹配表
- 细节不足 → 补充微纹理词（裂纹/划痕/毛孔/纤维）
- 表面太干净 → 加入环境交互描述（灰尘/水滴/风化）

### 维度六：⚙️ 参数合规 — 由⚙️参数师负责

| 问题 | 检查点 |
|------|--------|
| 画幅是否匹配用途？ | 海报=竖版，壁纸=横版/竖版，封面=方版 |
| 平台参数是否正确？ | MJ / Nano Banana / 即梦参数不同 |
| 风格强度是否合适？ | --stylize 值是否过高或过低？ |
| 是否需要 --raw 模式？ | 超写实场景建议加 --raw |

## 2. 调优决策树

用户回传图片或其效果描述后，按以下流程诊断：

```
用户反馈/描述生成效果
       │
       ▼
① 🎭 AD 整体评估（维度一）
       │
       ├─ 得分 ≥ 4 → 细节调优，进入单维度微调
       │
       └─ 得分 ≤ 3 → 进入诊断流程
                │
                ▼
② 各Agent逐维度诊断（维度二~六）
       │
       ├─ 明确问题维度 → 仅调度对应Agent
       │   e.g. "画面太亮了" → 💡光影师
       │   e.g. "风格不像水墨" → 🎨风格师
       │   e.g. "主体太小了" → 📷摄影师
       │
       └─ 无法确定问题 → 🎭AD重新审视创意简报
            ↓
           调性坐标需要调整？ → 更新创意简报，重启全流程
           简报没问题？ → 检查是否遵循了简报，如有背离则修正
```

### 单维度调优示例

| 用户反馈 | 诊断 | 调度Agent | 具体操作 |
|---------|------|----------|---------|
| "太冷了，想要温暖一点" | 💡色温偏冷 | 💡光影师 | 从蓝调改为黄金时刻/暖色调 |
| "背景太乱了，看不清主体" | 📷构图失衡 | 📷摄影师 | 加大光圈(f/1.4)，拉近焦段至85mm |
| "像塑料一样，不真实" | 🧱材质感差 | 🧱材质师 | 增加表面纹理、次表面散射、环境磨损 |
| "风格不太对，偏卡通" | 🎨风格偏差 | 🎨风格师 | 从插画风格改为写实摄影风格 |
| "画幅不对，我需要横版的" | ⚙️参数配置 | ⚙️参数师 | 将--ar 4:5改为--ar 16:9 |

## 3. 用户反馈解析指南

当用户用非技术语言反馈时，AD将其翻译为技术诊断：

| 用户说的 | 翻译为技术问题 | 谁负责 |
|---------|--------------|--------|
| "感觉不对" | 整体调性偏离 | 🎭AD（重新定调） |
| "太假了" | 材质/光影不真实 | 🧱材质师 + 💡光影师 |
| "不够好看" | 构图/色彩需优化 | 📷摄影师 + 🎨风格师 |
| "没内味儿" | 风格/氛围不精准 | 🎨风格师 + 💡光影师 |
| "太满了" | 密度过高，留白不足 | 🎭AD（密度轴调简洁） |
| "有点空洞" | 主体不突出或缺乏细节 | 📷摄影师 + 🧱材质师 |
| "太亮了/太暗了" | 明暗轴偏移 | 💡光影师（调整曝光/对比） |
| "颜色不好看" | 色温或配色偏离 | 💡光影师（调整色调） |

## 4. 评测报告输出格式

完成评测后，输出结构化的评测报告：

```markdown
## 📋 图片评测报告

### 整体评分：4/5 ✅ 基本满意

| 维度 | 评分 | 问题 | 调优方案 |
|------|------|------|---------|
| 🎯 整体印象 | 4 | 氛围不错，但偏暗 | - |
| 🎨 风格匹配 | 5 | 风格准确 | - |
| 📷 构图 | 3 | 主体不够突出 | 改为85mm f/1.4浅景深 |
| 💡 光影 | 4 | 光源方向略混乱 | 统一为左侧黄金时刻光 |
| 🧱 材质 | 4 | 岩石质感可再丰富 | 补充风化裂纹纹理词 |
| ⚙️ 参数 | 5 | 参数正确 | - |

### 调优操作
➡️ 调度 📷摄影师 + 💡光影师 协同修改
```

---

## 5. 多轮迭代机制

允许用户进行多轮"生成→评测→调优"循环：

```
第一轮：输出初始提示词方案 → 用户出图 → 评测 → 调优
第二轮：输出优化版提示词 → 用户出图 → 评测 → 调优
第三轮：...（直到用户满意为止）
```

**注意：** 每次迭代只修改被指出的维度，不要全面重写，减少对已满意部分的影响。
