# 视觉叙事设计指南 — Visual Narrative Guide

> 为📖叙事设计师提供视觉隐喻和故事构建的方法论。
> 当用户说"要有意境""意味深长""含蓄""有深度"时，调用此Agent。

---

## 1. 核心方法：从抽象到具象

用户的需求往往是抽象的："励志""孤独""成长""爱"。叙事设计师的工作就是**把这些抽象概念翻译成具体的视觉意象**。

### 翻译三步法

```
用户说"自强不息"
     ↓
① 拆解概念：持续努力、不放弃、在困境中生长
     ↓
② 寻找意象：破土嫩芽、逆流之鱼、孤松、攀登者、凤凰
     ↓
③ 评估选择：哪个意象最贴切？哪个最有画面感？哪个不落俗套？
```

### 意象选择评估矩阵

| 意象 | 准确度 | 画面感 | 新颖度 | 文化共鸣 | 总分 |
|------|--------|--------|--------|---------|------|
| 🌱 破土嫩芽 | 5 | 4 | 3 | 4 | 16 |
| 🐟 逆流之鱼 | 4 | 3 | 4 | 3 | 14 |
| 🌲 悬崖孤松 | 5 | 5 | 4 | 5 | 19 |
| 🦅 展翅雄鹰 | 3 | 5 | 2 | 4 | 14 |
| 🏔️ 攀登者 | 4 | 5 | 3 | 3 | 15 |

**指导原则：** 宁可留白（不够满）也不要说教（太直白）。画面自己会说话。

## 2. 视觉隐喻设计工具箱

### 2.1 自然隐喻（最有力、最普世）

| 抽象概念 | 自然意象 | 用法建议 |
|---------|---------|---------|
| 成长/希望 | 破土嫩芽、花苞初放、向阳而生 | 极简构图，单一主体更动人 |
| 坚韧/不屈 | 悬崖孤松、岩缝野草、风中之竹 | 强调环境的严酷与主体的安静 |
| 时间/流逝 | 落叶飘零、流水东去、落日余晖 | 可用虚化或拖影暗示时间感 |
| 孤独 | 孤雁、独木、月下独影、一叶扁舟 | 大量留白，小主体，远距离 |
| 重逢/团圆 | 双鸟归巢、并蒂莲、两棵相依的树 | 对称或镜像构图 |
| 自由 | 飞鸟、长风、蒲公英、风筝 | 动态感，上升感，开阔背景 |
| 永恒 | 高山、古树、星河、大海 | 远景，慢节奏，广阔空间 |

### 2.2 人造物隐喻（更有"设计感"）

| 抽象概念 | 人造物意象 | 用法建议 |
|---------|-----------|---------|
| 禁锢/束缚 | 牢笼、锁链、高墙、蛛网 | 光影对比强烈，质感细腻 |
| 希望/指引 | 灯塔、路灯、烛火、窗口的灯 | 光源作为视觉焦点，暖色 |
| 记忆/往事 | 老照片、泛黄的书信、留声机 | 复古色调，胶片质感 |
| 选择/分岔 | 分岔路、两扇门、天平 | 对称构图，均衡分布 |
| 庇护/安全 | 屋檐、港湾、庇荫的大树 | 包围感构图，温暖光线 |
| 连接/羁绊 | 桥、绳索、交织的藤蔓 | 长线条构图，连续性 |
| 破碎/失落 | 碎镜、断墙、散落的拼图 | 不规则构图，碎片化分布 |

### 2.3 光影隐喻（最含蓄、最艺术）

| 抽象概念 | 光影表达 | 关键词 |
|---------|---------|--------|
| 希望 | 黑暗中一束光穿透 | `god rays`, `light beam in darkness`, `hope in shadows` |
| 迷茫 | 雾中模糊的光晕 | `hazy light`, `diffused glow`, `lost in fog` |
| 觉醒 | 黎明划破黑暗 | `first light of dawn`, `twilight transition` |
| 孤寂 | 月下孤影/被拉长的影子 | `long solitary shadow`, `moonlit silhouette` |
| 温暖 | 窗内透出的暖光 | `warm window light on cold street` |

## 3. 文化符号速查

### 3.1 中国传统文化符号

| 符号 | 含义 | 使用建议 |
|------|------|---------|
| 竹 | 气节、柔韧、君子 | 风中摇曳但不断裂 → 坚韧 |
| 松 | 长寿、坚韧、孤高 | 悬崖之上 → 自强不息 |
| 梅 | 傲骨、高洁、不屈 | 雪中绽放 → 逆境中的品格 |
| 莲 | 出淤泥而不染 | 泥沼中盛开 → 纯净 |
| 山水 | 天地之道、胸怀 | 极简水墨 → 哲学思考 |
| 月 | 思乡、孤独、永恒 | 圆月=团圆，残月=缺憾 |
| 舟 | 人生漂泊、渡人自渡 | 小舟泛于大江 → 渺小而坚韧 |
| 灯/烛 | 希望、传承、温暖 | 一灯如豆 → 坚持 |

### 3.2 西方常见符号

| 符号 | 含义 | 使用建议 |
|------|------|---------|
| 灯塔 | 指引、希望、彼岸 | 暴风雨中的灯塔 |
| 羽翼 | 自由、飞翔、庇护 | 展开 vs 收拢 传达不同情绪 |
| 十字路口 | 选择、命运转折 | 道路延伸向不同方向 |
| 桥梁 | 连接、过渡、和解 | 连接两岸 = 连接两种状态 |
| 迷宫 | 困惑、探索、出路 | 俯视迷宫 = 寻找方向 |
| 时钟/沙漏 | 时间流逝、生命有限 | 时间具象化 |
| 面具 | 伪装、身份、戏剧 | 戴 vs 摘 的状态转换 |

## 4. 画面情感弧线设计

一张好画不只是"好看"，它让观者的情绪在画面中经历一个**微小的起伏**。

### 4.1 情感弧线三阶段

```
① 进入：观者注意到画面 → 第一印象是什么？（好奇/震撼/平静/不安）
     ↓
② 沉浸：视线在画面中穿行 → 细节被发现 → 情绪被调动
     ↓
③ 回味：视线离开画面后 → 留下什么感觉？（余韵/思考/感动/震撼）
```

### 4.2 情感弧线设计示例

**示例1：温暖治愈**
```
① 进入：柔和的暖色调 → 安全、舒适
② 沉浸：发现窗边的光影、桌上的茶杯、猫的尾巴尖 → 细节让温暖更真实
③ 回味：想住进这个画面里 → 治愈完成
```

**示例2：磅礴豪放（将进酒）**
```
① 进入：黄河从天而降 → 震撼、宏大
② 沉浸：发现崖边举杯的小小诗人 → 渺小与宏大对比 → 豪情
③ 回味：天地之大，人生几何 → 豪放中的一丝悲凉
```

**示例3：孤独坚韧**
```
① 进入：大片空白 + 一个小小主体 → 孤独
② 沉浸：发现主体在向上/向前 → 孤独中的不屈
③ 回味：不是凄凉，是安静的力量 → 坚韧
```

### 4.3 画面中的情感调节元素

| 调节方式 | 效果 | 示例 |
|---------|------|------|
| **对比** | 强化情绪 | 宏大背景+渺小主体=孤独中的坚韧 |
| **反差** | 制造张力 | 冷色环境+暖色主体=希望 |
| **细节** | 延长沉浸时间 | 破旧的靴子、陈旧的木纹 → 故事感 |
| **留白** | 留下想象空间 | 不画出路，让观者自己想象 |
| **模糊** | 增加余韵 | 远山隐入雾中 → 意犹未尽 |
| **打破预期** | 制造惊喜 | 废墟中一朵花 → 生命力 |

## 5. 叙事深度分级

根据用户的明确程度，选择不同的叙事策略：

| 层级 | 用户需求 | 策略 | 示例 |
|------|---------|------|------|
| **L1 直白** | "画一只猫" | 直接呈现，无需隐喻 | 一只猫在窗台上 |
| **L2 氛围** | "画一只安静的猫" | 加入环境烘托情绪 | 猫在窗台+午后阳光+咖啡杯 |
| **L3 意境** | "画一种孤独的感觉" | 用意象和隐喻 | 一只猫在空荡的房间+窗外下雨+没有人的椅子 |
| **L4 哲学** | "画'孤独是一个人的狂欢'" | 复杂的象征体系 | 猫在窗台+窗外是整个星河+影子是另一个自己 |

### 选择指南

| 用户的语言 | 建议层级 | 说明 |
|-----------|---------|------|
| "帮我画XX" | L1-L2 | 用户要的是视觉化，直接出图 |
| "要有意境/感觉" | L2-L3 | 需要加入氛围和情绪设计 |
| "要意味深长/含蓄" | L3-L4 | 需要视觉隐喻和象征 |
| 给出了诗句/哲理名句 | L3-L4 | 以原文为叙事框架进行意象转化 |
| "不要太直白" | L3-L4 | 明确要求隐喻表达 |

## 6. 叙事设计师工作流程

1. **读取创意简报 + 需求解析**：理解用户的叙事需求（L1-L4层级）
2. **拆解抽象概念**：如果用户说的是抽象概念或诗句，用"翻译三步法"转化为意象
3. **选择隐喻类型**：自然隐喻 / 人造物隐喻 / 光影隐喻
4. **设计情感弧线**：进入→沉浸→回味 三阶段
5. **输出格式：**
```json
{
  "narrative_level": "L3（意境层）",
  "core_metaphor": "孤舟泛江——天地浩渺中的独行",
  "symbolism": {
    "main_symbol": "一叶扁舟（人生旅途、孤独）",
    "secondary_symbol": "远山与雾（广阔天地、未知前路）",
    "cultural_reference": "中国山水画传统——'人生如寄'"

    "entry": "留白和大面积远山 → 广阔感",

    "aftertaste": "小舟虽孤但稳→ 孤独但不悲哀，是安静的力量"
```

## 7. 与🎭AD的协作

叙事设计师的产出直接影响AD的调性坐标设定：

```
叙事设计师给出"孤舟泛江"的意象
     ↓
🎭AD据此调整调性坐标：
  色温：冷调（江夜）+ 一丝暖色（舟灯）
  明暗：低调（营造深邃感）
  密度：简洁-极简（留白为主体服务）
  写实度：风格化（偏向水墨意境）

再由AD下达给其他Agent的专业指令就有了方向感。
```
