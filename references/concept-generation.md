# 概念发散与创意生成方法论 — Concept Generation Guide

> 为🧠概念设计师提供创意发散的参考框架。
> 核心思想：好的创意不是"匹配"出来的，是"碰撞"出来的。

---

## 1. 核心方法论：三方向并发

不要只朝一个方向死磕。对每个需求，同时推进3个完全不同方向的概念方案：

```
用户需求
     │
     ├─→ 方向A：直译（常规方案）
     │    "贴题、安全、稳定，用于兜底"
     │    例如罗城→船形古镇晨雾俯拍
     │
     ├─→ 方向B：错位（意外方案）
     │    "打破框架、跨界组合，最可能出惊喜"
     │    例如罗城→古镇被装进玻璃瓶像船模
     │
     └─→ 方向C：抽象（艺术方案）
          "远离具象、靠近概念，适合艺术表达"
          例如罗城→只画青瓦剪影+负空间拼出船形
```

### 三方向的筛选原则

```
方向A（直译）：✅ 必须保留，做兜底
方向B（错位）：✅ 优先推荐给用户
方向C（抽象）：✅ 用户说"艺术感/意味深长"时必出
```

---

## 2. 方向A：概念直译法

当用户需求可以直接视觉化时，使用最直接的意象。

**方法：** 中心词→直接视觉对应
**示例：**
- "船形街" → 直接俯拍船形
- "金樽对月" → 金樽+月亮
- "孤独" → 一个人+空旷背景

**特点：** 准确、清晰、可预测
**适用：** 用户需求明确且不要求"惊喜"时

---

## 3. 方向B：远距离联想法（核心创意工具）

**核心思想：** 从完全不相关的领域随机抽取一个元素，用它来重新理解原主题。

### 三步操作法

```
① 随机抽取一个不相关的"源领域"
   科技/料理/纺织/天文/植物/机械/医学/音乐/建筑/服饰...
   
② 从该领域提取一个"核心逻辑"而非"表面元素"
   例如抽到"料理"→ 核心逻辑是"配方/火候/调味/摆盘"
   
③ 用这个逻辑重新理解原主题
   原主题"爱如其所是"
   + 料理的核心逻辑"配方"
   → 爱不是完美的配方，是接受它不够咸但依然吃完
```

### 源领域速查表

| 领域 | 可提取的核心逻辑 | 适合转化的概念 |
|------|----------------|--------------|
| 🍳 **料理** | 配方、火候、调味、摆盘、发酵 | 不完美但完整的爱 |
| 🧵 **纺织** | 织法、经纬线、修补、编织 | 关系的修补与联结 |
| ⚙️ **机械** | 齿轮咬合、公差、磨损、传动 | 人与人的契合与摩擦 |
| 🌿 **植物** | 向光性、根系、嫁接、年轮 | 成长的痕迹 |
| 🎵 **音乐** | 和声、不协和音、休止符、即兴 | 不完美才是和声的一部分 |
| 🏛️ **建筑** | 承重、结构、风化、改建 | 时间的印记 |
| 📜 **书法** | 飞白、枯笔、墨韵、留白 | 残缺中的美 |
| 🧊 **天文** | 轨道、引力、光年、暗物质 | 见不到的才决定了轨迹 |

### 远距离联想示例

| 原需求 | 随机领域 | 提取逻辑 | 创意概念 |
|--------|---------|---------|---------|
| 罗城"意味深长" | ✈️ **航空** | 黑匣子——记录一切但沉默 | 古镇一角有一个"黑匣子"式的老邮局，里面封存着几百年来往的信件 |
| 爱如其所是 | 🧵 **纺织** | 织补——破洞不是终点 | 一件毛衣，肘部打着不同颜色的补丁，补丁上绣着小花 |
| 自强不息 | 🔧 **机械** | 公差——完美的咬合来自精确的间隙 | 两个齿轮，一个有缺口，另一个的齿刚好补上这个缺口 |
| 将进酒 | 🎵 **音乐** | 休止符——沉默是音乐的一部分 | 酒洒了一半，月光照在洒出的酒上，像休止符 |

## 4. 方向C：抽象概念法

当用户要求"艺术感""意味深长"时，使用抽象化策略。

### 方法：去中心化 + 留白 + 暗示

```
原主题 → 去掉主题中心词 → 保留最核心的1-2个元素 → 用负空间暗示全貌

示例1：
罗城"船形街" → 去掉"船形"的完整呈现 → 只画几片青瓦+一盏孤灯
→ 让观者自己拼出"船"

示例2：
"爱如其所是" → 去掉"爱"字 → 只画两根随意生长的藤蔓
→ 让观者自己完成"爱"的想象
```

### 抽象化的三个层次

| 层次 | 方法 | 典型效果 |
|------|------|---------|
| **L1 减元素** | 只保留50%的视觉元素 | 更像是"草稿"或"局部"，留想象空间 |
| **L2 换介质** | 用另一种材料/方式表达 | 例如文字内容"织"在布上而非写在纸上 |
| **L3 转概念** | 完全不去画原主题，去画它的"反面"或"影子" | 不说"孤独"，去画一个热闹人群中的空位 |

## 5. 创意约束机制

约束不是限制创意，而是**迫使创意找到新路径**。

### 5.1 五种约束类型

| 类型 | 方法 | 效果 |
|------|------|------|
| **禁止性约束** | 禁用某个最常见的元素 | 迫使跳出习惯思维 |
| **资源约束** | 只允许用N个元素 | 做减法激发创造力 |
| **跨界约束** | 必须借用另一个领域的逻辑 | 强制远距离联想 |
| **视角约束** | 从一个不可能的角度看 | 打破固化视角 |
| **格式约束** | 限定输出格式/风格 | 在限制中找自由 |

### 5.2 约束模板

在创意简报中新增约束字段：

```markdown
### 创意约束
- 禁止意象：[绝对不能用的元素]
- 跨界参考：[从哪个领域借灵感]
- 颜色限制：[故意去掉的色系]
- 元素上限：[画面中最多N个元素]
- 视角限制：[只能用某个特定视角]
```

### 5.3 约束示例

| 原需求 | 无约束方案 | 加约束后方案 |
|--------|-----------|------------|
| 罗城古镇 | 晨雾中完整船形 | 约束"禁止出现完整船形"→ 只画船头部分的青瓦和孤灯 |
| 爱如其所是 | 两句对比文字 | 约束"不能出现汉字"→ 用两株植物的向光方向暗示 |
| 少女摄影 | 唯美自然光人像 | 约束"去掉所有暖色"→ 蓝调+玻璃+水的冷感少女 |

## 6. Step 1.2 完整工作流程

```markdown
### Step 1.2：🧠 概念发散

需求解析完成后，概念设计师按以下步骤工作：

① 阅读需求解析表
② 根据用户需求判断是否需要发散：
   用户需求直白（"画一只猫"）→ 跳过，直接进Step 1.5
   用户需求有抽象/诗意成分（"意味深长"）→ 启动发散流程

③ 三方向并发：
   方向A（直译）：直接视觉对应，1句话写定
   方向B（远距离联想）：随机抽取源领域→提取逻辑→生成意外概念
   方向C（抽象概念）：去中心化→留白→暗示

④ 输出3个方向的概念方案给🎭AD

⑤ 🎭AD选择方向（或组合）进入定调和专业Agent阶段
   通常：方向A做兜底 + 方向B或C推给用户
```

### 输出格式

```json
{
  "concept_a": {
    "title": "船形古镇全景",
    "type": "直译",
    "one_sentence": "从高空俯瞰晨雾中的船形古镇，如同一艘古船在云海中航行",
    "creativity_score": "★★☆☆☆ 安全"
  },
  "concept_b": {
    "title": "瓶中古镇",
    "type": "错位（远距离联想：收藏）",
    "one_sentence": "古镇被装在一个老式玻璃瓶里，像一艘精致的船模，瓶口塞着软木塞，标签上写着'罗城·1628'",
    "creativity_score": "★★★★★ 惊喜"
  },
  "concept_c": {
    "title": "青瓦与影子",
    "type": "抽象（去中心化）",
    "one_sentence": "不画古镇，只画几片青瓦的剪影和一道被拉长的影子，用负空间暗示船形",
    "creativity_score": "★★★★☆ 艺术"
  }
}
```

## 7. Step 2.5 新增审查项：创意保留度

在一致性审查中增加一项：

```
⑧ 创意保留度检查
   □ 最终输出是否保留了发散的"方向B"或"方向C"？
   □ 经过各Agent的"优化"后，创意是否被磨平了？
   □ 如果创意被磨平 → 退回Step 1.2重新发散
```

**警告：** 各Agent有一天然倾向——把意外的概念"修正"成合理的概念。AD必须守住创意的锐度。
