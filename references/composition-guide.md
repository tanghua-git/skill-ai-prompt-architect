# 构图与平面构成指南 — Composition Guide

> 为📐构图师提供构图方法论的参考框架。
> 区别于📷摄影师（管镜头焦段），本指南聚焦于画面元素的平面构成。

---

## 1. 核心概念：什么是构图

构图不是在画面里"放东西"，而是**控制观者的视线路径和情绪节奏**。

好的构图回答三个问题：
1. **看到什么？** — 视线第一落点在哪里
2. **怎么看到？** — 视线如何移动（路径是直线还是曲线？快还是慢？）
3. **看完什么感觉？** — 构图的情绪（稳定/不安/流动/静止）

## 2. 经典构图模板

### 2.1 三分法构图 (Rule of Thirds)

**方法**：将画面横竖三等分，把主体放在四条分割线的交点上
**效果**：自然、平衡、有呼吸感
**适用**：人像、风景、日常摄影
**关键词**：`rule of thirds composition, subject placed on left third`

### 2.2 中心对称构图 (Central Symmetry)

**方法**：主体居中，左右/上下对称
**效果**：稳定、庄重、仪式感、神圣
**适用**：建筑、正式肖像、极简海报、科幻
**关键词**：`symmetrical composition, centered subject, mirror image balance`

### 2.3 引导线构图 (Leading Lines)

**方法**：用线条（道路、河流、廊柱、光影）将视线引向主体
**效果**：纵深感强、视线路径清晰
**适用**：风景、街道、走廊、室内
**关键词**：`leading lines composition, path引导视线 to subject, vanishing point`

### 2.4 框架构图 (Framing)

**方法**：用前景元素（门窗、树枝、拱门）框住主体
**效果**：窥视感、纵深感、聚焦主体
**适用**：人像、建筑、叙事场景
**关键词**：`framed composition, foreground frame, natural framing, looking through`

### 2.5 黄金螺旋 / 斐波那契螺旋 (Golden Spiral)

**方法**：按黄金比例螺旋线安排元素，主体位于螺旋终点
**效果**：最自然的视觉流动，经典美学
**适用**：油画、艺术摄影、需要"耐看"的画面
**关键词**：`golden ratio composition, fibonacci spiral, natural visual flow`

### 2.6 Z型 / S型构图 (Z-Curve / S-Curve)

**方法**：元素沿Z形或S形路径排布，引导视线在画面中穿行
**效果**：叙事感、流动感、适合大场景
**适用**：风景、群像、长卷、街景
**关键词**：`s-curve composition, serpentine path, z-pattern visual flow`

### 2.7 对角线构图 (Diagonal / Dynamic)

**方法**：主体或分割线沿对角线方向
**效果**：动感、不安定、有张力
**适用**：运动、动作、冲突场景
**关键词**：`diagonal composition, dynamic angle, tension, tilted horizon`

### 2.8 留白构图 (Negative Space)

**方法**：主体只占很小一部分，其余是大片留白
**效果**：孤独、宁静、高级感、引人遐想
**适用**：极简海报、情绪人像、山水意境
**关键词**：`extreme negative space, vast emptiness, tiny subject, minimal composition`

### 2.9 框架分层 (Layered Framing)

**方法**：前景→中景→背景三层清晰分层
**效果**：纵深感、身临其境
**适用**：风景、街景、大场面
**关键词**：`layered composition, foreground/midground/background, depth layering`

### 2.10 重复/图案构图 (Pattern / Repetition)

**方法**：利用重复元素（柱子、窗户、树木）形成节奏
**效果**：韵律感、秩序感、视觉冲击
**适用**：建筑景观、阵列、抽象
**关键词**：`repetition pattern, rhythmic elements, repeating shapes, visual rhythm`

## 3. 构图与情绪映射

| 构图类型 | 情绪效果 | 适合场景 |
|---------|---------|---------|
| 中心对称 | 庄重、稳定、神圣 | 宗教建筑、偶像、科幻母舰 |
| 三分法 | 自然、放松、日常 | 旅游照、人像、街拍 |
| 对角线 | 动态、紧张、不安 | 冲突、运动、危险 |
| 留白/负空间 | 孤独、宁静、高级 | 情绪人像、山水、单物 |
| 引导线 | 探索、旅程、纵深 | 道路、走廊、河流 |
| 框架 | 窥视、神秘、聚焦 | 窗口、门洞、树缝 |
| S型曲线 | 优雅、流动、蜿蜒 | 河道、人群、身体曲线 |

| 极低角度 | 宏大、压迫、崇高 | 建筑仰视、英雄、巨物 |
| 鸟瞰视角 | 俯瞰、抽离、平面化 | 城市、地图、微缩效果 |

## 4. 画面分割与视觉重量

### 4.1 视觉重量法则

画面中的不同元素"重量"不同：

| 重量级 | 元素特征 |
|--------|---------|
| **重** | 暗色 > 亮色；大 > 小；前景 > 背景；人脸/眼睛 > 物体；暖色 > 冷色 |
| **轻** | 亮色 > 暗色；小 > 大；背景 > 前景；纹理 > 纯色；冷色 > 暖色 |

**视觉重量平衡原则：**
- 左侧放一个重色物体 → 右侧需要更大面积的浅色来平衡
- 一个明亮的主体 → 周围需要足够的暗区来稳定
- 非对称平衡比对称平衡更有"设计感"

### 4.2 视线引导原则

| 原则 | 方法 |
|------|------|
| **视线第一落点** | 高对比区域 = 视线第一落点。设计者应控制这个落在哪 |
| **视线路径** | 用线条、边缘、人物视线方向引导观者移动 |
| **视线出口** | 不要让视线直接跑出画面，用边缘元素将其"兜住" |
| **视线停留** | 让视线在主体上停留足够久——减少竞争元素 |

### 4.3 画面分割比例

| 比例 | 感受 | 用法 |
|------|------|------|
| **50:50** | 均分、稳定、有点呆板 | 对称构图、倒影、正反打 |
| **1:2** | 主次分明、活波 | 最常见的黄金比例替代方案 |
| **1:3** | 强烈的主次关系 | 天空占1/3+地面占2/3 或 反之 |
| **黄金比 1:1.618** | 最自然舒适 | 经典绘画、建筑 |
| **1:9** | 极端留白 | 极简设计、孤独感 |

## 5. AI绘画中的构图控制技巧

### 5.1 用关键词控制构图

| 想要的效果 | 关键词 |
|-----------|--------|
| 视野开阔 | `wide angle view`, `grand vista`, `panoramic view` |
| 特写聚焦 | `close-up`, `intimate framing`, `tight crop` |
| 中景叙事 | `medium shot`, `waist-level framing` |
| 极低角度 | `low angle shot`, `worm's eye view`, `looking up at` |
| 俯拍 | `top-down view`, `aerial view`, `bird's eye view` |
| 微缩效果 | `tilt-shift effect`, `miniature scale` |
| 景深控制 | `shallow depth of field` (浅景深), `deep focus` (全景深) |
| 画面留白 | `negative space`, `minimal composition`, `vast emptiness` |

### 5.2 关于AI构图的注意事项

- **中心构图最稳定**：AI对中心主体的理解最准确
- **过度复杂的构图容易翻车**：三分法+引导线结合是最稳妥的"高级感"方案
- **用"视角词"控制比用"构图词"更有效**：写"低角度仰视"比"对角线构图"更直观
- **前景锚点能极大提升AI出片质量**：加上`sharp [物体] in the foreground`让画面立刻有纵深

## 6. 构图师工作流程

1. **读取创意简报**，理解AD设定的密度坐标和叙事意图
2. **选择构图模板**：根据画面情绪从第2节10种模板中选择
3. **确定视角**：平视/仰视/俯视/鸟瞰/微距
4. **设置画幅**：配合⚙️参数师确定（横版=16:9/3:2, 竖版=4:5/9:16, 方版=1:1）
5. **输出格式：**
```json
{
  "composition_type": "引导线构图",
  "viewpoint": "低角度仰视",
  "layers": {
    "foreground": "湿漉漉的柏油路面和铁轨",
    "midground": "霓虹灯下的街道和行人",
    "background": "高耸入云的摩天大楼和夜空"
  },
  "framing": "三分法+引导线，铁轨从右下角延伸到画面深处",
  "keywords": "low angle view, leading lines composition, foreground tracks guiding to distant city, deep focus, three-layer depth",
  "rationale": "低角度强化都市的压迫感和宏大感，引导线把视线从近处推向远景",
  "ad_note": "符合简报'宏大史诗'密度要求，三层法则增强了纵深感"
}
```
