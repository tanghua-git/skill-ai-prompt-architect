# 艺术指导框架 — Art Direction Framework

> 本框架为🎭艺术指导Agent提供方法论支持，统一视觉语言，确保多Agent产出方向一致。

---

## 1. 视觉调性坐标

在需求解析完成后、调度各Agent之前，AD先确定画面在四个维度上的坐标：

```
  冷调 ◄━━━━━━━━━━━━┳━━━━━━━━━━━► 暖调
                    ┃
  暗调 ◄━━━━━━━━━━━━┳━━━━━━━━━━━► 明调
                    ┃
  写实 ◄━━━━━━━━━━━━┳━━━━━━━━━━━► 风格化
                    ┃
  极密 ◄━━━━━━━━━━━━┳━━━━━━━━━━━► 极简
```

### 1.1 色温轴

| 位置 | 关键词 | 适合场景 |
|------|--------|---------|
| **暖调** | warm, golden, amber, cozy, sunlight | 治愈、怀旧、浪漫、温馨、史诗 |
| **中性** | neutral, balanced, true-to-life | 纪实、产品、自然风光 |
| **冷调** | cool, blue, cold, icy, steel | 科技、孤独、神秘、科幻、冬景 |

### 1.2 明暗轴

| 位置 | 关键词 | 适合场景 |
|------|--------|---------|
| **高调** | high-key, bright, airy, luminous | 治愈、极简、梦幻、小清新 |
| **中间调** | mid-key, balanced, natural | 纪实、日常、人像 |
| **低调** | low-key, moody, dark, dramatic | 电影感、神秘、暗黑、史诗 |

### 1.3 写实/风格化轴

| 位置 | 关键词 | 适合场景 |
|------|--------|---------|
| **超写实** | photorealistic, hyper-detailed | 产品摄影、建筑渲染、真实人像 |
| **写实** | realistic, natural, documentary | 纪实摄影、旅行、环境人像 |
| **风格化** | stylized, artistic, illustrative | 插画、概念艺术、游戏美术 |
| **抽象** | abstract, expressionist | 艺术创作、装饰画、实验风格 |

### 1.4 密度轴（留白度）

| 位置 | 关键词 | 适合场景 |
|------|--------|---------|
| **极密** | dense, rich, intricate, full | 奇幻、史诗、末日、赛博朋克 |
| **均衡** | balanced, composed, layered | 风景、场景、群像 |
| **简洁** | clean, simple, airy | 产品、头像、极简插画 |
| **极简** | minimal, vast negative space | 海报、封面、艺术表达 |

### AD 的用法

```markdown
## 创意简报

视觉调性坐标：
- 色温：暖调（温暖治愈）
- 明暗：中间调偏亮（温馨柔光）
- 写实度：写实偏风格化（真实但有艺术感）
- 密度：简洁（留白为主，突出主体）

核心指令：浪漫、温暖、唯美，不要冷峻或暗黑。
```

## 2. 创意简报模板

每个任务在Step 1.5由AD生成一份创意简报，发给所有专业Agent作为统一指令。

```
## 🎭 创意简报

### 项目概述
[一句话总结用户需求]

### 视觉调性坐标
| 维度 | 定位 | 说明 |
|------|------|------|
| 色温 | [暖/中性/冷] | [理由] |
| 明暗 | [高调/中间/低调] | [理由] |
| 写实度 | [超写实/写实/风格化/抽象] | [理由] |
| 密度 | [极密/均衡/简洁/极简] | [理由] |

### 统一指令
- 风格方向：[1-2个风格关键词]
- 禁止方向：[不适用的风格]
- 主光源方向：[明确单一主光源]
- 色彩约束：[主色调和禁止色]
- 情绪关键词：[2-3个情绪词]
```

## 3. 一致性审查矩阵

各Agent返回建议后，AD用以下矩阵检查是否一致。

### 3.1 风格 × 镜头 匹配检查

| 风格类型 | 推荐镜头 | 不推荐镜头 |
|---------|---------|-----------|
| 电影剧照 | 35mm, 50mm | 14mm鱼眼（除非特殊效果） |
| 纪实摄影 | 35mm, 28mm | 85mm人像（过于压缩） |
| 水墨画 | 非镜头——宣纸视角 | 任何相机参数 |
| 时尚杂志 | 85mm, 135mm | 24mm广角（畸变） |
| 赛博朋克 | 24mm, 35mm | 85mm（过于聚焦环境不够） |
| 极简产品 | 85mm, 50mm微距 | 14mm（畸变失真） |
| 风景宏大 | 16mm, 24mm | 135mm（过于压缩） |

### 3.2 光线 × 材质 匹配检查

| 天气/光线条件 | 材质表现 | 不匹配的信号 |
|-------------|---------|------------|
| 雨天 | 湿表面、反射增强、颜色加深 | 干燥哑光、灰尘粒子 |
| 黄金时刻 | 暖金色、长阴影、低对比柔光 | 冷蓝调、锐利阴影 |
| 雾天 | 低对比、边缘柔和、色彩去饱和 | 锐利边缘、鲜艳色彩 |
| 夜景月光 | 冷色、高对比、银色高光 | 暖色、柔和漫射 |
| 阴天 | 均匀漫射、高细节、低对比 | 强烈方向性阴影 |

### 3.3 风格 × 情绪 匹配检查

| 用户想要的情绪 | 应避免的风格 | 应选择的风格 |
|--------------|------------|------------|
| 温暖治愈 | 赛博朋克、暗黑、故障艺术 | 水彩、电影、黄金时刻、日系 |
| 冷峻科技 | 治愈系、水彩、田园 | 赛博朋克、极简科技、光影 |
| 神秘暗黑 | 高调、极简明亮、漫画 | 暗色调主义、电影低调、黑白 |
| 浪漫梦幻 | 纪实、新闻、伪纪录片 | 电影、柔光、梦幻、油画 |

## 4. AD决策流程

### 4.1 定调阶段（Step 1.5）

```
① 阅读需求解析结果
② 确定视觉调性坐标（四轴定位）
③ 填写创意简报模板
④ 将简报发给所有Agent作为统一指令
```

### 4.2 审查阶段（Step 2.5）

```
① 收集所有Agent返回的建议
② 用一致性矩阵逐项检查匹配度
   ├─ 全部匹配 → 放行到Step 3
   ├─ 1项不匹配 → 要求对应Agent重新匹配（附上指导）
   ├─ 多项不匹配 → 召回到Step 1.5，重新审视调性坐标
   └─ 风格不明确 → 调度🎨风格师补充2个备选方案
③ 检查核心句是否符合句子优先法（是否有明确的主谓宾）
④ 检查修饰图层是否遵循"减法原则"
```

### 4.3 减法原则（AD终审清单）

提交前逐项过筛：

```markdown
□ 有没有两个以上互相竞争的主体？ → 保留一个
□ 有没有两个方向相反的光源？ → 保留主光源，去掉干扰光
□ 有没有不必要的形容词？ → 删掉不能改变画面本质的词
□ 有没有同时出现不兼容风格？ → 只保留一种主导风格
□ 核心句能否用一句话讲清楚？ → 如果不能，画面也不会清楚
```
